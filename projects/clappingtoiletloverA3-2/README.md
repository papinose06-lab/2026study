# 변박사(clappingtoiletlover3-2)
숙명여대 중앙발명동아리, [엉뚱한 사람들]에서 진행한 <엉뚱한 발명대회> 프로젝트입니다.  
해당 프로젝트에서 부원 두 명과 함께 '변박사'를 발명했습니다.  
'변박사'는 '변기박수사랑'으로, 이는 화장실 변기를 사용한 사람들에게 박수를 치며 응원하는 기계입니다.  
아두이노 우노 보드를 바탕으로 GL5537 조도센서를 통한 감지시스템과 MG90S 서보모터를 이용한 기계의 동작을 구현했으며, 파이썬 pygame 라이브러리를 사용해 노트북에서 사운드를 출력하도록 구현했습니다.  
회로배선 작업 시, Tinkercad에서 우선 테스트를 진행하며 실제 작업을 이어나갔고, 코딩은 자연어 알고리즘 설계 후 AI(클로드Opus5.5)를 활용해 바이브코딩했습니다.  


|No|파일명|내용|
|---|---|---|

|2|soundplayer.py|사운드 출력|
|3|sound1.mp3|박수는 엉덩이를 춤추게 한다(Spanish-female)|
|4|sound2.mp3|이야-|
|5|sound3.wav|박수소리와 환호성|
